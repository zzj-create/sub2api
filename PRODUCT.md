# Product

## Register

product

## Users

Sub2API serves self-hosting operators, administrators, and technical teams that manage upstream AI accounts, API access, billing, routing, and network egress. In the admin interface, users need to inspect large operational datasets and act on accounts, proxies, and routing failures efficiently.

## Product Purpose

Sub2API is an AI API gateway for distributing and managing subscription capacity. The product provides authentication, metering, load balancing, request forwarding, account scheduling, and administrative control. Success means operators can keep upstream access reliable while understanding system state and correcting failures with minimal manual work.

## Brand Personality

Operational, precise, and dependable. Interface copy should be direct, state should be visible, and routine administration should feel predictable.

## Anti-references

Avoid marketing-style composition inside authenticated tools, oversized display typography, decorative animation, card-heavy layouts, and novel controls that obscure familiar administrative workflows.

## Design Principles

- Put current system state and actionable failures first.
- Make bulk operations efficient, explicit, and reversible where possible.
- Reuse established controls and interaction patterns across admin surfaces.
- Keep dense data scannable without hiding important status details.
- Preserve operator trust with clear loading, empty, success, and failure states.

## Accessibility & Inclusion

Maintain keyboard-accessible native controls, visible focus states, readable contrast in light and dark themes, responsive layouts, and reduced-motion compatibility. Do not rely on color alone to communicate health or failure.
